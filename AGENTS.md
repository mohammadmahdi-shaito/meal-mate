# Agent Guidelines

This repository is in its foundation phase. Agents should preserve the documentation-first setup until implementation work is explicitly requested.

## Current Rules

- Do not add backend, frontend, or ML implementation code unless specifically asked.
- Keep changes small and aligned with the repository structure.
- Prefer documentation updates when clarifying scope, architecture, or planning.
- Do not introduce dependencies, package managers, build systems, or generated project scaffolds without approval.

## Repository Areas

- `docs/` contains shared planning and architecture documentation.
- `backend/` is reserved for the future API and server-side application.
- `frontend/` is reserved for the future client application.
- `ml-service/` is reserved for future machine learning or recommendation services.

## Verification

Before finishing a task, check that no unintended implementation files were added.
