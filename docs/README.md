# Documentation

This directory contains planning and architecture documentation for Meal Mate.

## Files

- `PRODUCT_REQUIREMENTS.md` - product purpose, MVP scope, and future features.
- `ARCHITECTURE.md` - system design, service responsibilities, and recommended folder structure.
- `DATABASE_DESIGN.md` - planned entities and relationships.
- `API_DESIGN.md` - backend API modules and initial endpoint ideas.
- `ML_PLAN.md` - future machine learning recommendation plan.
- `DEVELOPMENT_ROADMAP.md` - phased build order and recommended first tasks.

No application code belongs in this directory.
